A. Type dropdown in the search bar (recommended)

A dropdown sits at the right of the search field, the way Raycast's file search does it. ⌘P opens it, ↑/↓ and ↵ pick. ⌘1 to ⌘4 jump straight to the common ones. When a type is picked, the dropdown turns blue and the results narrow. Backspace in an empty field does not clear it; ⌘0 or picking All types does.

B. Suggestion rows and completion

No new control. The "Use … with…" section gets type rows next to the two that exist today. Picking one adds the matching text (kind:dir, type:image) to the query, so you learn the syntax as you go. Typing type: or kind: pops up the allowed values.

It shows the filter clearly, costs no space and works before you type. It's the most work, mostly in the panel's keyboard handling.

Open questions for any option: if you pick Folders and also type type:image, which wins? (My call: the typed one, and the dropdown shows Custom.) Should the choice stick when you reopen the panel later? (My call: only within the 60-second resume window, like the query.)
